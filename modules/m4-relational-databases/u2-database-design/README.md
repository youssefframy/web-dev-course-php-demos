# Unit 2: Database Analysis & Design

You will take a written scenario through five stages:

1. Gather the requirements.
2. Draw a logical design.
3. Refine it into a physical design for MariaDB.
4. Turn the design into SQL.
5. Add data and check that it fits.

The running example is ICEAdmin, a small system that stores ICE Malta's employees, departments and salaries. Four exercises (a restaurant, rivers, an art gallery and a TV studio) give you practice at each stage.
